# Phase 1 integration design

Use the reviewed module layout: domain/application ports in core, synthetic provider implementations, infrastructure adapters, and a Tauri composition root. React displays typed backend results through restricted IPC. One locale service controls en/zh-CN display without changing reporting zones or native units.

Numeric/time/coverage contracts precede storage and UI. Storage precedes lifecycle journals; journals precede secrets and collection. Restricted IPC connects these to the UI. Bilingual shell work can follow the contract task independently of backend adapters. Integrate screens and native lifecycle before the final failure/performance review and native viability assessment.

No task is permitted to silently replace a release requirement with simulation. Later-phase features retain their original phase and acceptance obligations. See each child's design for its bounded prototype scope.

Rollback follows individual task branches and tested synthetic-state migrations. Never use a real credential or personal database to demonstrate recovery. A failed native requirement or benchmark stays visible and prevents the corresponding phase exit criterion from passing.
